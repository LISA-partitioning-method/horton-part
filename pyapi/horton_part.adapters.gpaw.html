horton_part.adapters.gpaw module

Convert a legacy GPAW restart into a HORTON-Part periodic density archive.

This module is adapted from denspart.adapters.gpaw on DensPart’s lisa branch at commit ce0d986. GPAW is imported lazily so that it remains an optional interoperability dependency.
